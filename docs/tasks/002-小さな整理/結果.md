## 確認1：検証コマンド

`bun run check` は成功、終了コード0でした。実行環境は Bun 1.3.14、Node 24.11.1、Biome 2.6.3 です。

`--error-on-warnings` は警告でも失敗させる指定です。検査はソースの書き換えを行いません。

検査そのものも、一時フォルダーへコピーしたファイルだけを壊して確認しました。

| 一時コピーへ加えた異常 | 結果 |
|---|---|
| manifest に存在しない `src/main/missing.js` を追加 | 終了コード1。ファイルを戻すか manifest のパスを直すよう案内 |
| `src/main/bad-syntax.js` に `const = ;` を追加 | 終了コード1。対象ファイル・構文エラー・修復後の検証コマンドを案内 |
| 同ファイルにトップレベルの `return 1;` | 終了コード1 |
| 同ファイルに ES module の `import` | 終了コード1 |
| MAIN に `console.log(chrome.runtime)` を追加 | `noUndeclaredVariables` により終了コード1 |
| ISOLATED に同じ参照を追加 | 終了コード0 |

構文エラーの案内には「該当ファイルの括弧・引用符・宣言を直し、bun run check を再実行してください」と出ます。

当初 Bun の `node:vm` で `new Script()` を生成する方法を試しましたが、不正な `const` を検出できませんでした。出荷する検査は Bun から既存の Node を起動し、Node の `vm.Script` で構文解析します。対象ソースを実行せず、classic script で使えない構文も検出します。Bun と Node の両方が必要である点は構成資料にも記載しました。

追加確認として、CSS の実行時文字列は指定のクラス名変更を除き変更前と一致しました。README・bun.lock・開始時の `.gitignore` の内容、devDependencies のバージョンも開始時の控えと一致しています。`git diff --check` は終了コード0でした（既存 `.gitignore` の LF → CRLF 予告はあります）。

独立した確認役も旧版との照合と `bun run check` を実施しました。指摘を直した後の再確認で、追加の具体的な問題は見つかりませんでした。ただし、実ブラウザ上の動作を確認したという意味ではありません。
