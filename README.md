# X Follow Review Probe

Xのフォロー整理拡張を作る前段階として、現在のX Webが実際に使っているGraphQL operation・queryId・リクエスト変数・レスポンスの**構造**を観測するための最小Chrome拡張です。

## 目的

次の4系統を確認します。

1. Following
2. Bookmarks
3. UserMedia / UserTweets
4. ListsManagementPageTimeline / ListMembers などのList系

queryIdは固定せず、Xが実際に行った通信から取得します。

## プライバシー上の挙動

- Authorizationヘッダーの**値**は保存しません。
- Cookie本文は保存しません。
- CSRFトークンの値も保存しません。
- `webRequest`側では、それらのヘッダーが「存在したか」だけ記録します。
- GraphQLレスポンス本文そのものは保存せず、キー・配列構造・型を要約した `shape` のみ保存します。
- requestの `variables` も値そのものではなく構造・型だけを保存します。
- `__typename` や `cursorType` 等、パーサ実装に必要な構造判別文字列だけ残します。長い数値IDは `<id>` に置換します。
- データは `chrome.storage.local` のみです。
- 「診断JSONをコピー」では、観測元タブURLやrequestIdも除外します。

## インストール

1. `chrome://extensions/` を開く
2. 右上の「デベロッパー モード」をON
3. 「パッケージ化されていない拡張機能を読み込む」
4. このリポジトリをclone/downloadしたフォルダを選択
5. Xにログインした通常のタブを再読み込み
6. 拡張機能のアイコンをクリックすると診断画面が開く

## 観測手順

診断画面を開いたまま、別タブのXで順番に以下を操作します。

1. 自分のプロフィール →「フォロー中」→ 少しスクロール
2. 「ブックマーク」→ 少しスクロール
3. 任意のフォロー相手 →「メディア」→ 少しスクロール
4. 「リスト」→ 自作リストを1つ開く → メンバー一覧も表示

診断画面では自動更新されます。必要なら「更新」を押してください。

## 次に欲しい情報

4系統を一通り観測したら「診断JSONをコピー」を押し、そのJSONをChatGPTに貼れば、現在のXのレスポンス構造に合わせて次段階のX Adapterを実装できます。

## 注意

この拡張は診断専用です。まだフォロー取得の自動ページネーション、ブックマーク同期、リスト同期、フォロー解除は行いません。
