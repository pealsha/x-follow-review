# X Follow Review

Xでフォロー整理を楽にするためのChrome拡張機能です。自分用に作ったので、使いたい方がいれば使ってください。
一つの画面から、その人の投稿した画像・その人の投稿で自分がブックマークしているものなどのフォロー整理に参考になる情報を見ることができます。

> ベータ版です。X の公式 API ではなく X Web が内部で使っている API を利用しているため、X 側の変更で突然動かなくなることがあります。X Corp. 公式の拡張機能ではありません。

## 見られるもの

左の一覧では、各ユーザーについて次の情報が分かります。

- 相手が自分をフォローしているか
- その人の投稿を自分がブックマークした件数
- その人を入れている自分のリストの数

右の詳細には、選んだ人の情報が表示されます。

- プロフィール、最近の画像・動画
- 自分がブックマークした、その人の投稿
- リストへの追加・削除、フォロー解除（解除するときは確認が出ます）

名前か `@handle` をクリックすると、その人の X のプロフィールが新しいタブで開きます。

## インストール

Chrome Web Store では配布していないので、パッケージ化されていない拡張機能として読み込みます。

```powershell
git clone https://github.com/pealsha/x-follow-review.git
```

1. `chrome://extensions/` を開く
2. 「デベロッパー モード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」で、clone した `x-follow-review` フォルダを選ぶ
4. 開いている X のタブを再読み込みする

## 使い方

1. X にログインした状態で `https://x.com/<自分のユーザー名>/following` を開く
2. `Review Mode` を押す
3. 左の一覧からユーザーを選ぶ

初回は、フォロー・ブックマーク・リストの情報をすべて取得するため時間がかかります。量が多いほど長くなります。2 回目以降は、前回の内容をすぐに表示してから、最新の状態に更新します。

## 表示がおかしいとき

Review Mode の上部に、2 つのボタンがあります。

- `強制再同期`: 保存済みのデータは表示したまま、X から最新の情報を取り直します
- `キャッシュ初期化`: この拡張が保存したデータをすべて消して、最初から取得し直します

X の画面でリストを大きく編集した後なども、これらで表示を合わせられます。

## 更新

```powershell
cd x-follow-review
git pull
```

その後、`chrome://extensions/` で X Follow Review を再読み込みし、X のタブを閉じて開き直してください。タブを再読み込みするだけでは、古い処理が残ることがあります。

## 保存するデータ

表示を速くするため、フォロー・ブックマーク・リスト・メディアの情報を、ブラウザ内の `chrome.storage.local` に保存します。

X の認証に使う情報（Authorization ヘッダー、Cookie、CSRF トークン）は保存しません。これらは X のページのメモリ上でだけ扱います。

## 開発者向け

内部構成やデータの取得方式は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) にまとめています。

拡張機能のアイコンから開ける GraphQL 診断画面は、X の仕様変更を調べるためのものです。通常の利用では開く必要はありません。
